\# Jenkins Shared Library CAFS



Shared Library utilizada por Jenkins para automatizar:



\- Construcción y publicación de imágenes Docker.

\- Actualización del backend en Kubernetes.



\## Steps



\### dockerBuildAndPush



Construye y publica una imagen Docker en Docker Hub.



\### deployKubernetes



Actualiza la imagen del Deployment del backend en Kubernetes.
